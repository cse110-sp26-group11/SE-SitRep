# Domain Research: Agile Team Software Features
## Must Have Features:

### 1. Progress "Dashboard"
- In sites such as Monday.com, the landing page has a table with tasks, due dates, and progress. There is also a similar feature in Notion.
- Dashboard is a visual indicator of progress, with either circular or linear progress bars.

### 2. Person Chips
- A way to assign a person to a project or task. A lot of places use person chips, which has the person's name and an icon, which shows contact information when clicked or hovered.
- Showing the contact information on hover seems like a good alternative to having a chat feature. 

### 3. Standup Form
- Standup form which directly integrates into the dashboard. Allows team members to enter their progress and blockers in a centralized location.


## Domain Research:
### Monday.com
PROS:
- Visually appealing, colorful
- Dashboard shows progress visually
- Organized, spreadsheet like design

CONS:
- Expensive
- Can require a lot of customization before the tool is useful

### Notion
PROS:
- Allows users to make sub pages for different tasks
- Folders for different documents
- Mobile version exists
- Built in widgits like calendar, date, person

CONS:
- Limited ammount of people in free version
- Limited number of "blocks" avaliable to use in free version
- Though there are templates, users need to customize the page entirely on their own, which can take time

## Overview
The most important thing for us to focus on is having a easy to use, clean dashboard which has customization options, but doesn't require a lot of customization to get going. 
It should be colorful and visually appealing without being too cluttered. 
Useful information should be accessable at a glance, and you shouldn't have to go down a "click hole" to find pages you are looking for.
