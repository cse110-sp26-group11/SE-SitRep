# Domain Research: Agile Team Situation Awareness (SE SitRep)
## Core Features (Top 3 Must-Haves)

### 1. Information Aggregation
- A unified feed that surfaces the latest updates every developer needs to know, presented in a concise and digestible format.
- Reduces information overload and ensures no one misses critical updates without having to dig through multiple tools.

---

### 2. Real-Time Code Integration
- Automatic synchronization with GitHub/GitLab so that code changes, commits, and pull requests are instantly reflected on the platform.
- Developers can track progress without manual updates, keeping the team aligned with the actual state of the codebase.

---

### 3. Member Status & Task Distribution
- A clear overview of each team member's current assignments, workload, and availability to support effective management.
- Helps managers identify imbalances in task distribution and reassign work before bottlenecks occur.

---

## Competitive Platforms

### 1. GitHub Projects
**Pros:**
- Directly surfaces GitHub activity including issues, PRs, and commits
- No separate account creation needed — connects directly to existing repos
- Clear workflow visualization tied to actual code progress

**Cons:**
- Complex interface for new users with no clear starting point
- Text is small and dense, making quick scanning difficult

---

### 2. Jira
**Pros:**
- Tailored views for different roles including designers and developers
- Built-in "Ask for Assistance" feature for blockers
- Supports task breakdown, assignment, and priority setting
- Integrates with GitHub

**Cons:**
- Account creation process is slow and adds friction
- Left sidebar is cluttered with too many options

---

### 3. Linear
**Pros:**
- GitHub connection for real-time code sync
- Auto-connects to school organizations for easy onboarding
- Clean and organized left navigation compared to Jira
- Built-in AI features for workflow assistance

**Cons:**
- Authentication bugs reported during setup
- Auto-connection to school orgs raises privacy concerns
- Requires paid plan for full features
- Cannot leave a team if you are the only member, only delete it

---

## Key Takeaway

The core goal of SitRep is to give development teams instant situational awareness with minimal manual effort. Unlike existing tools that require constant manual updates or suffer from feature overload, SitRep should automatically pull in code activity and surface only what matters. By combining real-time GitHub integration, concise information aggregation, and a clear member status overview, SitRep aims to be lightweight, intelligent, and built specifically for the way software teams actually work.
